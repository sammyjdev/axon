# Claude Code integration

Harness-side pieces. These are NOT part of the `axon` package — they run inside
the agent's harness, which is the only place they can work from. Kept here so
they are versioned and survive a machine.

## `axon-search-first.py` — PreToolUse(Read)

Two jobs:

**1. Emits the denominator.** An MCP server only observes the calls it received,
so it is structurally blind to the file reads that happened *instead of* a
`search_code` call. Every code Read under `~/dev` is logged to
`$AXON_ENGINE/data/recall/opportunities.jsonl`, which is what turns the
per-call savings ratio into delivered savings. Consumed by
`axon.observability.coverage` and the `recall.coverage` doctor check.

**2. Nudges once per session.** `mcp__axon__*` tools arrive deferred in Claude
Code — the model must call `ToolSearch` before `search_code` exists for it. So
at the moment it chooses between `Read` and `search_code`, the AXON.md golden
rule is asking for a tool that is not on its menu. The hook injects that missing
step. It also tells the model to fall back to Read/grep if the search comes back
off-target, and not to retry — a nudge that overrides evidence is worse than no
nudge.

See `docs/adoption-diagnosis-2026-08-07.md` for the measurements that motivated it.

### Install

```bash
cp contrib/claude-code/axon-search-first.py ~/.claude/hooks/
chmod +x ~/.claude/hooks/axon-search-first.py
```

Then add to `~/.claude/settings.json`:

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Read",
        "hooks": [{"type": "command", "command": "~/.claude/hooks/axon-search-first.py"}]
      }
    ]
  }
}
```

Scope: files under `~/dev` with a code suffix (`.py .ts .tsx .js .jsx .rs .java
.go .rb .sh`). Reads outside that are not counted, so coverage is measured
against the tree AXON actually indexes.

Never fails a Read: any error exits 0 silently.

## `session-start-context.sh` — SessionStart

One line, no file needed:

```json
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "",
        "hooks": [{"type": "command", "command": "[ -f .axon/context.md ] && cat .axon/context.md || true"}]
      }
    ]
  }
}
```

Injects the repo's recent decisions at session start. `.axon/context.md` is
regenerated by `axon_session_end`; a stale copy is fine, it carries its own
timestamp. This is the "IL-2" option in `~/.claude/axon/ROUTER.md` — documented
since 2026-07-16 and, until 2026-08-07, never actually installed. Session
capture ran at 6 sessions in 3 months while it sat unused.
